# Fun Friday Games - Implementation Plan

- Database: H2 (Embedded DB)
- Use JHipster for project scaffolding and code generation.
- Use Docker for containerization of all applications. Use best practices for containerization and development.
- Use docker-compose for easy startup of the applications.

**Highest priority**
- Follow best coding practice.
- Robust and expandable design, So I can easyly add new games later with minimal code changes.
- Make the code highly easy maintainable.
- Clean and smooth communication between be and fe. Use proper API design and architecture with real-time communication where needed.
- All game logic should be self contained within a single folder, including fe and be.
- If needed add embedded db for persistence.
- Smooth, elegent minimulistic UI/UX with smooth transitions and animations.

**Other requirements**
- Code should be well documented.
- Code should be well organized.
- Functionality should be well tested. No need for unit testing for now.
